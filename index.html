featured project

GitHub Actions continuous deployment

A CI/CD pipeline built with GitHub Actions, Packer, Terraform, and Ansible that takes a commit all the way to a running, zero-downtime deployment in AWS — without anyone touching a server by hand.

01GitHub Actions
02Packer
03Terraform
04Ansible

GitHub Actions automates the build, test, and deployment process, triggering the pipeline on every commit and pull request. Packer then builds an immutable, custom AMI so every deployment starts from the same known-good image. Terraform provisions the AWS infrastructure itself — EC2 instances, load balancers, and auto-scaling groups — and Ansible handles configuration management, rolling the latest version of the application out across instances with no downtime.

The stage above shows the pipeline at its initial trigger — GitHub Actions kicking off the AMI build while Terraform provisions the surrounding infrastructure in parallel.
